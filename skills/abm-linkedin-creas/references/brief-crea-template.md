# Canevas de créa (à remplir pour chacune des 9 créas)

Reproduire ce bloc pour chaque créa. Pour le Type 3, un bloc par décideur (+ le gabarit).

---

## Créa [X.Y] — [Type] · [sous-angle]

**Type** : Visibilité / Ads chiffré / Nominative
**Objectif** : une phrase (ce qu'on veut déclencher chez le prospect).

**Angle**
> Le levier (référence/preuve sociale, révolution du moment, crédibilité, chiffre-problème,
> interpellation nominative) et pourquoi il marche sur CE compte maintenant (source Phase 0).

**Copy LinkedIn complet**
- Accroche : …
- Corps : … (court, une idée ; pour le Type 2, le chiffre est en tête)
- CTA : … (Type 1 = soft ; Type 2 = conversion ; Type 3 = « Échangeons ensemble »)

**PROMPT IMAGE (prêt à coller — obligatoire)**
> Consigne exécutable. Doit préciser :
> - format/ratio (1080×1080, 1200×627, 1080×1350…) ;
> - **univers du PROSPECT dominant** : couleurs (hex), codes/lieux/métiers ;
> - texte exact à incruster (le vrai copy / chiffre / nom) ;
> - **placement des DEUX logos** : prospect au premier plan + client en signature ;
> - style, ambiance. Pour le Type 3 : champ variable `[Prénom Nom]` + intitulé.
> Écrire le prompt entre triple backticks, prêt à coller.

**Personne visée (Type 3 uniquement)**
> Prénom Nom · Intitulé · Métier · statut (réel / `[MOCK — à remplacer]`).

**Assets requis**
> Logos (prospect + client), chiffre + actu source (URL + date), logos de pairs (Type 1)…
> `[À CONFIRMER]` si non fourni.
