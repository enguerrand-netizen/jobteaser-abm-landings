# JobTeaser — Agent de Landing Pages ABM 1-to-1

Landing pages ABM **hyper-personnalisées** (émetteur **JobTeaser** → un compte cible), produites par un
**agent** qui orchestre une chaîne de skills spécialisées.

## Contenu
- `lp-jobteaser-sanofi/` — pilote **JobTeaser × Sanofi** (page + assets).
- `lp-jobteaser-bulldozer/` — page **JobTeaser × Bulldozer**.
- `skills/` — les modules de l'agent ABM (design-system, gates qualité, résolveur de logos, etc.).

## Ce que l'agent fait, par compte
- **Co-branding réel** : couleurs, typo et logos officiels du compte (jamais de logo IA).
- **Personnalisation sourcée** : signaux réels et datés → angle sur-mesure.
- **Créas dédiées** : visuels sectoriels + motion vidéo aux 2 accents.
- **Contact humain** : section « Rencontrez [commercial] » (photo, Calendly, téléphone).
- **Contrôles qualité automatiques** : co-branding présent/lisible, logos, 0 placeholder, mobile.

## Ouvrir une page
Ouvrir `lp-jobteaser-sanofi/index.html` (ou `index-standalone.html`, autonome) dans un navigateur.
